>
> Антивирус может среагировать на WinDivert.  
> WinDivert перехватывает и фильтрует трафик, поэтому нужен для работы zapret.
> Такой инструмент могут применять и безопасные, и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует файлы WinDivert как инструменты с повышенным риском или хакерские средства. В результате файл удаляется и отправляется в карантин. Название обнаружения при этом обязательно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с zapret в исключения антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, Kaspersky содержит настройку "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". При уверенном понимании настроек лучше создать исключение, а если вы не вполне понимаете последствия, рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и выберите DNS-провайдера, отличного от "Поставщик по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", нажмите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query`, поскольку Cloudflare может оказаться заблокирован
    * В Windows 11 Secure DNS можно активировать непосредственно в параметрах системы - [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот способ рекомендуется
    * Владельцам роутеров Keenetic нужно включить в настройках параметр "Транзит запросов". Если его отключить, настройка и работа Secure DNS на компьютере могут нарушиться

2. Получите zip/rar-архив с [последнего релиза](https://github.com/Eastacrossblast/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и включите флажок "Разблокировать". При использовании 7-Zip или PeaZip этот пункт можно пропустить

4. Извлеките архив в каталог, путь к которому не содержит кириллицу и специальные символы

5. Запустите нужный скрипт
    * Чтобы найти работающую стратегию: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для включения автозапуска: **`service.bat`** -> `Install Service` -> *выберите подходящую стратегию*

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) - ручной запуск стратегии

  Такой запуск удобен для проверки разных стратегий. Результат зависит от множества условий, поэтому **перебирайте варианты (ALT, FAKE и другие), пока не найдёте подходящий именно для вас**

- [**`service.bat`**](./service.bat) - автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - добавление выбранной стратегии в автозапуск (services.msc)</ins>
  - **`Remove Services`** - удаление стратегии и WinDivert из списка служб
  - **`Check Status`** - просмотр состояния обхода и служб, включая автозапущенную стратегию и WinDivert
  - **`Game Filter`** - изменение режима обхода для игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После изменения параметра стратегию нужно запустить заново.**  
  В скобках показывается текущее состояние (включено/выключено).
  - **`IPSet Filter`** - выбор режима обхода для сервисов, перечисленных в `ipset-all.txt`.  
  Это полезно при проверке ресурса, который без zapret работает, а с ним - нет  
  В скобках отображается состояние:
    - `none` - проверка не применяется ни к одному IP
    - `loaded` - IP сопоставляются со списком
    - `any` - под фильтр попадает любой IP  
  - **`Auto-Update Check`** - включение или отключение автоматической проверки обновлений
  - **`Replace active fakes`** - замена текущего фейка на другой файл из каталога `bin`
  - **`Update IPSet List`** - загрузка свежего `ipset-all.txt` из репозитория
  - **`Update Hosts File`** - обновление hosts <ins>**для восстановления веб-версии Telegram и голосового чата Discord**</ins>
  - **`Check for Updates`** - ручной поиск обновлений
  - **`Run Diagnostics`** - поиск распространённых причин неисправности zapret.  
  В конце процедуры можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает неожиданно переставший работать клиент
  - **`Run Tests`** - запуск проверки стратегий:
    - `Standard tests` - тестирование сайтов из `utils/targets.txt`
    - `DPI checkers` - проверка DPI у разных провайдеров (Cloudflare, Amazon и других)


## ☑️Распространенные вопросы и проблемы

### После запуска `general*` нет видимого результата

- При запуске стратегии отдельным bat-файлом, а не через service, процесс обхода winws.exe должен появиться на панели задач.  
Если его нет, обратитесь к [#522](https://github.com/Eastacrossblast/zapret-discord-youtube/issues/522)

### Не подходит ни одна стратегия
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, скрипт предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота
  - Откройте текстовый редактор от имени администратора и через него найдите файл `hosts` в появившемся каталоге
  - Вставьте скопированное в конец `hosts` или замените ранее добавленные аналогичные строки
  - Сохраните файл и проверьте соединение. Если результата нет, убедитесь, что изменения действительно записались.

#### Работа не гарантируется. При неудаче используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Eastacrossblast/tg-ws-proxy) либо с любым публичным прокси.

### Обход перестал работать или не запускается

> [!IMPORTANT]
> **Стратегия может со временем потерять работоспособность.**
> Даже если конкретный вариант некоторое время работает, обнаружение его параметров может привести к прекращению работы.
> В проекте собрано много стратегий обхода. Если готовые варианты не помогают, создайте новую на основе одной из них и измените её параметры.
> Описание параметров стратегий находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте наличие ошибок через `service.bat` -> `Run Diagnostics`

- Убедитесь, что ресурс добавлен в списки доменов или IP-адресов

- Испытайте другие стратегии, включая **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/Eastacrossblast/zapret-discord-youtube/issues/765)

### Как полностью обновить или переустановить проект?
- Сохраните добавленные вами ресурсы и данные
- Перезагрузите устройство
- Откройте `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`, исправьте найденные ошибки и в конце выберите Y
- Удалите каталог zapret
- Скачайте свежую версию со [страницы релизов](https://github.com/Eastacrossblast/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Откройте свойства архива через ПКМ. Если внизу справа есть флажок разблокировки, нажмите его, затем `Применить` и `ОК`
- Распакуйте архив в новый каталог в корне диска, без пробелов и специальных символов
- Запускайте разные скрипты `general` и проверяйте интернет-ресурсы. Если доступ не работает, закройте программу через значок замка на панели задач и попробуйте следующую стратегию
- Найдя рабочий вариант, добавьте его в автозапуск через `service.bat` -> `Install Service` -> выбор стратегии

### Игра или приложение не работает при включённом обходе

- В `service.bat` проверьте, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Используйте инструкцию: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть среди служб

1. Определите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал противодействовать таким расширениям.
- Попробуйте остальные стратегии, особенно если раньше доступ уже работал.
- Смотрите также [#251](https://github.com/Eastacrossblast/zapret-discord-youtube/discussions/251)

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) настроен
- Сначала желательно определить стратегию, на которой открывается сайт YouTube, и запустить её
- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord
- Повторно проверьте приложение Discord. Изменилась ли ситуация после очистки кэша?
- Откройте Discord в браузере: https://discord.com/app. Если браузерная версия работает, можно пользоваться ей
- Если Discord не работает и в браузере, снова проверьте все стратегии. YouTube и Discord могут работать на разных вариантах
- См. также [#252](https://github.com/Eastacrossblast/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Установите [tg-ws-proxy](https://github.com/Eastacrossblast/tg-ws-proxy)
- Либо подключите бесплатный MTProto-прокси из интернета

### Не работают игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Начните с универсальной последовательности:
- обновите ipset через `service.bat` и включите `Game Filter`
- если это не сработало, дополнительно включите `ipset any`

Учтите: режим `ipset any` может нарушить открытие большого числа сайтов. Не держите его включённым постоянно. Определите IP-адреса, которыми пользуется игра, и внесите их в `ipset-all.txt`

Если проблема сохранится, создайте обсуждение в [Discussions](https://github.com/Eastacrossblast/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли подходящего ответа

- Оформите вопрос [здесь](https://github.com/Eastacrossblast/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса для обхода указываются в следующих файлах:
- **`list-general-user.txt`** - домены; поддомены включаются автоматически
- **`list-exclude-user.txt`** - домены-исключения, например когда IP-сеть есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно
- **`ipset-all.txt`** - IP-адреса и подсети
- **`ipset-exclude-user.txt`** - IP-адреса и подсети, которые требуется исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
